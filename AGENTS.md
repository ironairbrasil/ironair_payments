# Regras obrigatórias do usuário

- Trabalhar e escrever somente nos arquivos locais deste projeto em Downloads.
- Nunca executar `git commit`, `git push` ou qualquer alteração no GitHub sem pedir confirmação explícita ao usuário imediatamente antes.
- Nunca publicar, promover, reverter ou executar deploy sem pedir confirmação explícita ao usuário imediatamente antes.
- Testes, builds e validações locais são permitidos sem confirmação.
- Quando o usuário autorizar commit e deploy, executar diretamente, com comunicação mínima. O usuário confere o resultado; não iniciar auditorias adicionais sem solicitação.
